# Propuesta CIMAT · Consorcio Médico Mius

Presentación dinámica en HTML (20 diapositivas) con formato ejecutivo, portada animada y la plataforma interactiva **Health Tower Intelligence** en la diapositiva 17.

**Ver la presentación:** https://colchadito.github.io/propuesta-cimat-mius/

## Controles

| Tecla | Acción |
| --- | --- |
| `←` `→` / `Espacio` | Anterior / siguiente |
| `G` | Índice de diapositivas |
| `F` | Pantalla completa |
| `Inicio` / `Fin` | Primera / última |

También funciona con gestos táctiles y rueda del ratón. Al abrir `index.html#17` se salta directo a la diapositiva 17.

## Estructura

```
index.html            las 20 diapositivas
deck.css / deck.js    estilo (azul marino, azul eléctrico, cian) y visor
diagramas.css / .js   diagrama interactivo de la plataforma
assets/               imágenes optimizadas (WebP)
```

No requiere compilación: basta abrir `index.html` en un navegador. La página incluye `noindex`, por lo que los buscadores no la listan.
